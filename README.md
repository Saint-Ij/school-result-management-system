# School Result Management System

A full-stack school result management system built with Next.js to streamline student records, score entry, attendance, grading, and automated report generation.

## Features

- Student management
- Teacher management
- Class and subject management
- Score and attendance entry
- Automatic grade calculation
- Automated report sheets
- Admin, teacher, and student portals
- Role-based access control
- Academic session and term management
- Responsive design

## Tech Stack

- Next.js
- TypeScript
- React
- PostgreSQL
- Tailwind CSS

npm install
npm run dev
